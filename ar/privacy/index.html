إشعار الخصوصية

يوفر هذا الدليل الثابت التصفح والبحث ومعلومات المشاريع. ولا يوفر حسابات أو إرسال مشاريع أو مدفوعات أو خدمة ترتيب.

يُصفّي البحث المشاريع عادةً داخل المتصفح ويضع كلمات البحث في العنوان وسجل التصفح. إذا لم يُحمّل النص البرمجي، يرسل النموذج الكلمات عبر طلب GET. وقد تُرسل أيضًا إلى مزود الاستضافة أو المستلم عند إعادة تحميل عنوان البحث أو مشاركته. لا تدخل معلومات شخصية أو سرية.

تستضيف GitHub Pages هذا الموقع. تسجل GitHub عناوين IP للزوار وتخزنها لأغراض أمنية سواء سجّل الزائر الدخول أم لا. تُعالج معلومات الطلبات الأخرى وفق بيان الخصوصية الخاص بها. لا يضيف هذا الدليل نصوص تحليل أو أدوات تتبع إعلانية أو نظام حسابات.

للاستفسارات المتعلقة بالخصوصية، استخدم البريد أدناه. إرسال رسالة يشارك عنوانك ومحتواها مع مزود البريد والمشغّل لمعالجة الاستفسار؛ أرسل المعلومات الضرورية فقط.
