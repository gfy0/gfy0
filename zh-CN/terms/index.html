使用说明

本目录提供浏览、搜索和项目信息。项目建议可通过 GitHub 公开提交，经审核后视情况收录。本网站不提供自己的账户系统、付款服务或排行榜服务。

你可以浏览目录并分享公开链接。外部网站独立运营，适用各自的条款和隐私说明。内容可能更新或停止提供。

简介仅用于初步了解。最新功能、许可和使用条件，请以链接指向的项目原始来源为准。

公开建议一个项目

需要登录 GitHub。你的 GitHub 身份和建议内容会公开展示。请勿填写个人、机密或付款信息。

这只会建立一条供后续考虑的公开建议，不是匿名投稿或私有回执，提交本身不会立即启动审核，也不保证收录。不收取任何费用。
