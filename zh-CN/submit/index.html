公开建议一个项目

发现了值得了解的项目？可以在 GitHub 提供项目名称、官方公开链接和简短说明。

需要登录 GitHub。你的 GitHub 身份和建议内容会公开展示。请勿填写个人、机密或付款信息。

提交或编辑投稿会启动云端核验。保存同一条记录即可查看结果，不收取费用。

打开公开项目建议表单

请保存 Issue 网址，查看其开启或关闭状态及答复。你可以在 GitHub 编辑自己的建议。若提交失败，请先检查是否已生成记录，避免重复提交。
