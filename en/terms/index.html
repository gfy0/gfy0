Using this directory

This directory provides browsing, search and project information. Project suggestions can be submitted publicly through GitHub and may be listed after review. This site does not provide its own account system, payment service or ranking service.

You can browse the directory and share its public links. External websites are independent and have their own terms and privacy notices. Content may change or become unavailable.

Descriptions are brief introductions. Check the linked original source for current features, licensing and any conditions that apply to using each project.

Suggest a project publicly

GitHub sign-in is required. Your GitHub identity and suggestion will be public. Do not include personal, confidential or payment information.

This creates a public suggestion for consideration, not an anonymous submission or private receipt. Submitting does not start an immediate review or guarantee publication. No payment is requested.
