About the directory

A curated, free-to-browse project directory. Explore descriptions and follow links to the original sources.

This static directory provides browsing, search and project information. It has no accounts, submissions, payments or ranking service.

Projects are selected from public sources. Listing order is not a ranking, recommendation or endorsement. A listing does not imply affiliation with the project.

Descriptions are brief introductions. Check the linked original source for current features, licensing and any conditions that apply to using each project.
