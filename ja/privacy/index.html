プライバシーについて

この静的ディレクトリは閲覧、検索、プロジェクト情報を提供します。アカウント、投稿、決済、ランキングの機能はありません。

通常、検索はブラウザ内でプロジェクトを絞り込み、検索語を URL と閲覧履歴に残します。スクリプトが読み込まれていない場合、フォーム送信時に GET リクエストで検索語が送られます。検索 URL の再読み込みや共有でも、ホスティング事業者や共有相手に送られる場合があります。個人情報や機密情報を入力しないでください。

このサイトは GitHub Pages で公開しています。GitHub はログインの有無にかかわらず、安全対策のため訪問者の IP アドレスを記録し保存します。その他のリクエスト情報は同社のプライバシー声明に従って扱われます。このディレクトリは解析スクリプト、広告用トラッカー、アカウント機能を追加していません。

プライバシーに関するお問い合わせは下記メールへお送りください。送信すると、対応のためにメール事業者と運営者へアドレスと本文が共有されます。必要な情報だけをお送りください。

フィードバックは任意で、GitHub が処理し、公開します。GitHub アカウントで送信した場合、アカウント情報がフィードバックとともに表示されることがあります。個人情報や機密情報を含めないでください。プライバシーに関するお問い合わせには、代わりにこのページのプライバシーに関する連絡先をご利用ください。

プロジェクトを公開で提案

GitHubへのログインが必要です。GitHub上のあなたのアカウント情報と提案内容は公開されます。個人情報、機密情報、支払い情報を入力しないでください。

これは検討用の公開提案であり、匿名投稿や非公開の受付票ではありません。自動審査は開始されず、掲載も保証されません。料金はかかりません。
