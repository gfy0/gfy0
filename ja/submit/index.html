プロジェクトを公開で提案

紹介したいプロジェクトがありますか？名前、公式の公開URL、簡単な説明をGitHubで共有できます。

GitHubへのログインが必要です。GitHub上のあなたのアカウント情報と提案内容は公開されます。個人情報、機密情報、支払い情報を入力しないでください。

投稿または編集するとクラウドで確認を開始します。同じ記録を保存して結果を確認してください。料金はかかりません。

公開提案フォームを開く

IssueのURLを保存すると、オープン・クローズの状態や返信を確認できます。提案はGitHubで編集できます。送信に失敗した場合は、重複を避けるため先に記録が作成されていないか確認してください。

投稿結果を確認

審査は運営者のパソコンを使わずクラウドで実行します。対応するオープンソースライセンスがある、GitHub 組織管理の公開リポジトリを提案できます。README 全文は20,000文字以内で、プロジェクト名と用途を述べた短い原文の行が必要です。リスク、不確実性、確認できない点がある場合は掲載しません。出典が変わると承認を停止します。GitHub の稼働状況に依存し、処理時間や掲載は保証しません。 投稿はすぐに保存されます。定期審査は毎時最大1件で、順番待ちや GitHub の遅延により長くかかる場合があります。短い出典の説明は英語で記載されている必要があります。審査に失敗したら、同じ投稿を編集して再度審査待ちにできます。

審査対象の開発ツール

  • コードフォーマッター
  • ソースコードのリンター
  • 型チェッカー
  • コンパイラー

ページ公開後にのみ掲載を確定します。公開に失敗するとクラウドの復旧処理が再試行します。重複投稿は不要です。
