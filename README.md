# Your No.1

[Explore Your No.1](https://gfy0.github.io/gfy0/) — a free project directory in English, Simplified Chinese, Spanish, Arabic and Japanese. Browse and search published projects, then visit their official sources.

[Suggest a project](https://gfy0.github.io/gfy0/en/submit/) through GitHub. A GitHub account and sign-in are required; your GitHub identity and suggestion content are public. Do not include personal, confidential or payment information.

Review runs in the cloud without the operator’s computer. Suggest public GitHub repositories maintained by organizations with a supported open-source license. The complete README must be within 20,000 characters and include a short plain-text line naming the project and describing its purpose. Risky, uncertain or unverifiable projects are not listed. Source changes pause approval. Processing depends on GitHub availability; no completion time or listing is promised. Submissions are saved immediately. Scheduled cloud review processes at most one new project per hour; queues and GitHub delays can take longer. The short source description must be in English. If review fails, edit the same suggestion to queue it again. Supported categories are code formatting, source-code linting, type checking and compilation. Existing listed projects return their current page. The result page links to a project only after its live page is verified. Temporary source or publication failures are retried in the cloud.

The pilot is free. Payments and paid rankings are not enabled.
