# Your No.1

[Explore Your No.1](https://gfy0.github.io/gfy0/) — a free project directory in English, Simplified Chinese, Spanish, Arabic and Japanese. Browse and search published projects, then visit their official sources.

[Suggest a project](https://gfy0.github.io/gfy0/en/submit/) through GitHub. A GitHub account and sign-in are required; your GitHub identity and suggestion content are public. Do not include personal, confidential or payment information.

Cloud review currently supports only the exact pre-reviewed sources [ESLint](https://github.com/eslint/eslint), [Prettier](https://github.com/prettier/prettier), and [TypeScript](https://github.com/microsoft/TypeScript). Changed source identities or reviewed versions are held. Other new sources receive a not-listed result; general-purpose review is not available. Existing listed projects return their current page. No response time or listing is promised. The result page links to a project only after publication is verified. Processing runs on GitHub-hosted infrastructure and does not require the operator's computer to be on.

The pilot is free. Payments and paid rankings are not enabled.
