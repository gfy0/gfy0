Acerca del directorio

Un directorio de proyectos seleccionados que puedes explorar gratis. Lee sus descripciones y visita las fuentes originales.

Este directorio permite explorar, buscar y consultar información sobre proyectos. Las sugerencias de proyectos pueden enviarse públicamente a través de GitHub y podrían incluirse tras su revisión. Este sitio no ofrece un sistema propio de cuentas, servicios de pago ni clasificaciones.

Los proyectos se seleccionan a partir de fuentes públicas. El orden no representa una clasificación, recomendación ni respaldo. La inclusión no implica afiliación con el proyecto.

Las descripciones son introducciones breves. Consulta la fuente original para conocer las funciones actuales, las licencias y las condiciones de uso de cada proyecto.

Directorio gratuito · Sugerencias públicas en GitHub · Sin pagos.
