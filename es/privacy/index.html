Aviso de privacidad

Este directorio estático permite consultar y buscar información sobre proyectos. No ofrece cuentas ni clasificaciones y no acepta propuestas de proyectos ni pagos.

La búsqueda normalmente filtra proyectos en el navegador y coloca las palabras en la URL y el historial. Si el script no se ha cargado, enviar el formulario las transmite en una solicitud GET. Recargar o compartir una URL de búsqueda también puede enviarlas al alojamiento o al destinatario. No introduzcas información personal ni confidencial.

Este sitio se aloja en GitHub Pages. GitHub registra y almacena las direcciones IP de los visitantes por seguridad, hayan iniciado sesión o no. Otra información de las solicitudes se trata según su declaración de privacidad. Este directorio no añade scripts de análisis, rastreadores publicitarios ni un sistema de cuentas.

Para consultas sobre privacidad, utiliza el correo indicado abajo. Al enviar un mensaje, compartes tu dirección y su contenido con el proveedor de correo y el operador para atender la consulta; incluye solo lo necesario.
